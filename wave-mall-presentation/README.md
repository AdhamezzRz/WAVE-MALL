# Wave Mall · Location & Market Study (interactive presentation)

A self-contained website: open `index.html` or upload this folder to any static host
(Netlify, Vercel, GitHub Pages, cPanel, S3...). No build step, no server code, no external
services needed. Powered by NAJ · https://najmarketing.co

## Files
- `index.html` the presentation (24 slides, English + Arabic)
- `assets/` scripts, styles, fonts, three.js, the Higgsfield concept film (`wave-concept-film.mp4`)
- `src/` + `build.py` editable source; run `python3 build.py` to regenerate `index.html`

## Presenting
| Key | Action |
|---|---|
| → ↓ Space / ← ↑ | next / previous slide (also swipe, scroll, or the buttons) |
| M | slide menu | L | switch English / عربي |
| F | fullscreen | N | speaker notes | A | auto-present (14 s per slide) |
| Slide 5 | drag to orbit the 3D site, scroll to zoom, click categories and labels |

Deep links work: `index.html#explore`, `#catchment`, `#fork` ...

## Honest caveats shown inside the deck
- The 3D scene uses real OpenStreetMap offsets around the pin; roads and the building
  massing are schematic. The building size is a visual estimate from the satellite shot.
- The concept film is AI-generated mood footage, not the approved design.
- Most project and price data comes from broker listings and is unverified.
- Arabic copy needs a native review before client use.
