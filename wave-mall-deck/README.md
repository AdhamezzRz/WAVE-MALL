# Wave Mall logo deck
`python3 build.py` builds `../wave-mall-logo-deck.html`, a single file (fonts, logos, images inlined).
Keys: arrows/space/swipe to move, A / B / S on comparison slides, F for fullscreen.
Logos: the two supplied logo images (wave-mall-mockups/src/logoA.png, logoB.png), converted to transparent PNGs by build.py.
