# "The WAVE" sign, recreated as clean vector

Hand-built from the night photo of the lit sign (small bold rounded "The" + WAVE drawn as
flowing wave strokes, E as three wavy bars). All lettering is monoline strokes with round caps.

- `build_logo.py` generates every SVG (edit shapes, widths, colours there; `python3 build_logo.py`)
- 01 neon look (warm glow on black) · 02 gold/black · 03 black/ivory · 04 forest/ivory · 05 ivory/emerald
- 06-08 transparent (black, ivory, gold)

This is a faithful visual reconstruction from a low-resolution photo, NOT the official artwork.
If the owner has the original files, use those and let a designer compare.
