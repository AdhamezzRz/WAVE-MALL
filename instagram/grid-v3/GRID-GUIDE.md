## Text fixes before publishing

1. **Badge (5):** "MORE THAN A DESTI**NAN**TION" is misspelled. It should read **MORE THAN A DESTINATION**.
2. **Everything you need (3):** "ALL WHAT YOU NEED" is not correct English. Use **EVERYTHING YOU NEED,** / *and more.* Also left-align it like the other posts, so it doesn't break into a stray "NEED" line.
3. **Shopping or chilling (6):** "THIS TIME SHOPPING OR *chilling?.*" has a double "?.". Use **SHOPPING TODAY, OR** / *just chilling?*. A shorter option is **SHOPPING OR** / *chilling?*
4. **The building (4):**
   - Remove the small pink square to the right of the paragraph.
   - Turn hyphenation off ("SHOP-PING", "EXPE-RIENCES").
   - Write the name the same way as everywhere else: **THE WAVE**, not "WAVE MALL". Suggested text: *A MODERN DESTINATION FOR SHOPPING, DINING AND LIFESTYLE. THE WAVE BRINGS A FRESH PERSPECTIVE TO NEW CAIRO, A PLACE WHERE CONTEMPORARY DESIGN MEETS EVERYDAY LIFE.*
5. **More than a destination (8):** "WELCOME TO THE WAVE MALL" should be **WELCOME TO THE WAVE,** / WHERE EVERY DETAIL MAKES A STATEMENT. The logo says THE WAVE, so the copy should too.
6. **Newspaper (9):**
   - In the small print, "New cairo" should be **New Cairo**, and "Wave Mall" should be **The Wave**.
   - "SEE YOU SOON" announces an opening. Earlier you asked to leave opening news out of the bio, so consider **SHOP · DINE · CONNECT** instead.
7. **Dinner or lunch (7):** people say lunch before dinner: **LUNCH OR** / *dinner?* Also move the script word clear of the wine glass, which currently cuts through "lunch".
8. **Everywhere:** finish the script line with one mark only: *a lifestyle.* / *and more.* / *chilling?* / *dinner?*
